# 丽水嘉园176㎡ · R5概念深化包

11页A3横向方案册：西墙电视与东侧浮放沙发同轴；餐桌和座椅全部进入C；新增独立储藏室，阳台B作为洗烘家政间。

- A/B/D保留卧室，两卫不移位；原餐厅先保通道，再分独立储藏室和L形书房。
- 储藏室目标约1400–1600×1800–2000mm、约2.5–3㎡，书房目标约5–6㎡；均非实测面积，储藏净使用还须扣隔断、层板和机器人龛。
- C西侧非承重墙宽开口延续，粗墙/梁柱、C/D隔墙及东侧外墙窗保留。R5封原C北门洞，北侧集中冰箱与干备餐柜，中厨连接口向东研究并可关闭。
- 餐桌1600×800，可延伸1800×800；六人长边各三人，不放端头椅。撤掉C南侧和窗侧深柜，实际椅后、柜前及冰箱开门需放样。
- 阳台B叠放洗烘，清洁工具浅挂收纳，核保温、污水、承载、门窗及拆机。R01为储藏室朝公共区独立壁龛条件位，关厨房及储藏门仍可出入；合法水路未核定，不通过则撤回重选。
- 西墙北段H03咖啡餐边柜保持水箱式、手动加水倒废水，仅接电。C无新增水槽、无独立岛台。

`python deliverables/build_package.py` 重建HTML、SVG、CSV，会覆盖同名生成资料；人工改过的表格请先保存副本或同步源数据。

`python deliverables/render_verify.py` 渲染PDF及检查，需要Playwright、PyMuPDF、Pillow和Chromium/Edge；可用 `FURNISH_BROWSER` 指定浏览器路径。GitHub排除PDF、ZIP、缓存、临时资料及任何受保护文件。
