# 丽水嘉园176㎡ · R8连续餐厨与贴墙冰箱

打开[方案册.html](方案册.html)离线阅读或打印。14页方案册、01–09 SVG、七份UTF-8 BOM CSV与预览图同步由`build_package.py`生成；局部尺寸试排源为`r8_geometry.py`。

- 冰箱背靠公卫南墙东段，门朝南面向餐区，避西侧公卫门。柜宽900–1000起排，深度/背部散热/开门侧余量按型号；前场1200–1400禁摆咖啡柜及餐椅。
- 上部水槽—600–800净备菜台—灶连续，洗碗机在水槽旁备菜台下直线段、避转角。主备菜面不放常驻小电器，岛台仅补充操作。
- 原厨房与C连续统筹；岛1000×750，1600×800餐桌向南连接，可延伸1800。错位量按冰箱前场、家政路和餐椅调整，不固定400，也不挤客厅休息区。
- 咖啡柜在C/D隔墙西段、背南朝北，宽1200–1400、深550–600。水箱机仅接电，手动加水倒废水。
- 保燃气及合规可关闭分隔，从公卫南墙附近起排，约100–200微调；开启/关闭均核收门、操作与阳台B通路。未成立处明确记录冲突。
- 取消客厅独立储藏室；家庭厅600–650深大件柜配浅书柜、保办公及A/B通行。鞋柜入户门内北侧1000–1200×350，向家庭厅侧收并避门。
- 保西墙沙发、投影幕与D路线；洗烘清洁在阳台B，机器人L02阳台B/R01公卫干区二选一。

## 冲突与图纸边界

第11–13页分别画四/六人、拉椅、冰箱门/抽屉满开、洗碗门与装卸站位、分隔开/闭及七类动线。原图3976/2998/2844只作初排依据；局部墙面原点和设备包络是明确标注的算例。

当前试排东侧拉椅余226、六人桌尾248，不能作为900通行带；椅包络虽避冰箱与咖啡前场，边缘仅余60/50，不证明转弯成立。阳台B门洞与分隔关闭关系、公卫南墙净长及设备安装尺寸须现场核验。未标为已验证可施工。

`verification.json`仅记录文档排版、清单一致性与试排算术，不是现场或燃气验收。七份CSV含17项家具、13项设备、18处点位、15项现场核验、11项原图面积、7项原图尺寸、15行设备上下水。

## 生成与发布

在仓库根运行`python deliverables/build_package.py`，然后`python deliverables/render_verify.py`。需要Playwright、PyMuPDF、Pillow和Chromium/Edge；支持`FURNISH_BROWSER`。本地PDF为`方案册-R8.pdf`，文件状态见`PDF文件保护说明.txt`。

原生Git提交/推送；继续排除PDF、ZIP、加密/受保护文件、缓存和临时资料。使用可正常读取的HTML/SVG/CSV及预览，不移除文件保护。
