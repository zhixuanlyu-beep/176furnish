# 丽水嘉园176㎡ · R7概念深化包

13页方案册：原书房与旧通道合并共享家庭厅；西墙沙发＋东侧可收纳投影幕；冰箱外移、洗碗机在直线柜段，开门装卸净空单独校核。

- 原餐厅14.4㎡已包含旧方案划出的通道，本版取消专用走廊隔断，改阅读/办公＋墙边300–400深封闭收纳。A/B入口不动，厅内保1000–1100净通行目标；不是把通行彻底消除，也不是隔声独立书房。
- 不推荐整厅作为穿行式储物间。大件行李的独立储藏仍保留客厅西北角约2.5–3.2㎡研究位，和贴墙沙发北端、入户转弯一起核实。
- 沙发沿西墙，东侧设置独立平面的吊装可收纳幕，幕后900–1000通行目标去D；幕落下也能走。100–110英寸16:9仅选型起点，镜头至幕距离、投射比、坐距、遮光、噪声及吊装/检修待实测。
- 冰箱移出原厨房，研究入口外、原公卫南方的独立柜，面朝西侧公共区；两侧不顶墙，前方1200–1400操作区起研，主通行另留。供电和散热可达，普通无外接水机型优先。
- 洗碗机保原厨房水槽东邻的北侧直线柜段，避开东侧L转角。开门投影P＋装卸人位S单独画出；同时通行还须加T，不能用关门净距或站位重复计算。
- 保留燃气及合规可关闭分隔、C与客厅联通、岛东桌西相连、C南侧靠东水箱咖啡柜。岛台无水无火，咖啡机手动加水倒废水，仅接电。
- 机器人仍首选L02阳台B，备选R01公卫干区，不另占公共区。清扫时开必要房门，合法污水、防溅、设备前场及门槛待核。
