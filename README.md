# 丽水嘉园176㎡ · 三卧＋独立书房＋开放餐区

当前方案为 **R4：C西侧宽开口联通客厅**。

- A、B、D保留三间卧室，原餐厅部分隔出单人书房，保留卧室通道。
- 打开C西侧非承重隔墙，与客厅共享餐区；保留承重部分、梁柱、C/D隔墙及东侧外墙窗。
- 中厨保持可关闭，水火和洗涤留在中厨；C配置冰箱、食品收纳及干备餐台，不新增水槽或独立岛台。
- 餐桌在C与客厅交界借位，日常四人、偶尔六人。
- 客厅西墙北段安排咖啡餐边柜：水箱式咖啡机手动加水、倒废水，仅接电。
- 洗烘及自动上下水机器人先核合规水路、通行和检修，再确定安装位置。

## 本地生成

Python 3运行：

```shell
python deliverables/build_package.py
```

这会重建HTML、SVG和CSV。人工修改过的清单应先保存副本或同步至源数据。

需要重新渲染与检查时，安装`playwright`、`pymupdf`、`pillow`，并准备Chromium/Edge浏览器，然后运行：

```shell
python deliverables/render_verify.py
```

可用环境变量`FURNISH_BROWSER`指定浏览器可执行文件路径。检查覆盖分页、中文内容、图片加载、CSV数量与编号及移动端横向溢出；不代表现场尺寸或施工验收通过。
