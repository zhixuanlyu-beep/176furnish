# 丽水嘉园176㎡ · 三卧＋独立书房＋开放餐区

当前方案为 **R6：岛台连接餐桌、餐区咖啡柜、完整书房与储藏室另选位**。已确认保留燃气，接受按当地要求设置可关闭分隔。

- A、B、D保留三间卧室；原餐厅扣卧室通道和入口过渡后恢复完整书房，取消书房内储藏隔断。
- C西侧联通客厅，原厨房南/西可拆细墙段研究大开口和可收合分隔；保留粗墙、梁柱、公卫边界、C/D墙和东窗。厨房所有开放面须构成合规关闭周界，不能只装一面门。
- 灶、水槽、洗碗机留原厨房；岛台作干备餐。撤销旧C北侧柜列和封原C北门决定，冰箱移到原厨房实墙段条件位，需与厨台和收门共同放样。
- 岛1200×800、高850–900，桌1600×800、高约750，可延伸1800；东西向端接，岛东桌西，桌端适度借客厅。四/六人长边各二/三人，无端头椅；全部尺寸为规划目标。
- 电视在客厅西墙南段，东侧浮放沙发面向西，中心对齐；沙发背后至D门目标净通道1000–1100mm。
- H03餐边柜移至C南侧靠东，与餐椅错开，宽1400–1600、深550–600起研；水箱咖啡机手动加水倒废水，仅接电。岛台无水无火。
- 独立储藏室推荐客厅西北角、原咖啡柜附近，净约2.5–3.2㎡目标，独立门朝公共区；次选D西北角分隔小间，阳台A不优先。推荐位尚未定案，须核入户转弯、客厅和餐桌通道。
- 阳台B集中洗烘、清洁工具及机器人首选L02；机器人备选R01为原公卫干区，两处二选一，不另占公共空间。
- 阳台方案清扫须开厨房/阳台门，燃气烹饪关门时暂停跨区任务；公卫方案须开公卫门并避淋浴溅水。两处合法上下水、净宽、前场和湿区电气条件都需核实。

## 本地生成

Python 3运行：

```shell
python deliverables/build_package.py
```

这会重建HTML、SVG和CSV。人工修改过的清单应先保存副本或同步至源数据。

需要重新渲染与检查时，安装`playwright`、`pymupdf`、`pillow`，并准备Chromium/Edge浏览器，然后运行：

```shell
python deliverables/render_verify.py
```

可用环境变量`FURNISH_BROWSER`指定浏览器可执行文件路径。检查覆盖分页、中文内容、图片加载、CSV数量与编号及移动端横向溢出；不代表现场尺寸或施工验收通过。

文件通过本地Git提交与推送，保留增量历史，无需经模型参数传递Base64。
